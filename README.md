# KATA - Ejercicios de Python

Autor: David Jiménez

## Descripción

Repositorio de ejercicios prácticos realizados para reforzar conocimientos de programación en Python.

El objetivo del proyecto es practicar la resolución de problemas mediante pequeños ejercicios, aplicando buenas prácticas de programación y comprobando el funcionamiento del código mediante pruebas sencillas.

---

## Contenido

Actualmente incluye ejercicios como:

- FizzBuzz
- Funciones matemáticas
- Funciones auxiliares
- Uso de assert
- Ejercicios de lógica

---

## Tecnologías

- Python
- Git
- GitHub

---

## Objetivo

Este repositorio sirve como colección de ejercicios realizados durante el proceso de aprendizaje de Python y como apoyo para mejorar la lógica de programación y la escritura de código limpio.
